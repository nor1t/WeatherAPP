# WeatherAPP

A modern weather application that provides accurate and up-to-date weather information for multiple locations and countries.

## 📖 Overview

WeatherAPP is a clean, intuitive weather application designed to deliver real-time weather data. It offers comprehensive weather insights including temperature, humidity, wind speed, and multi-day forecasts for locations around the globe.

## ✨ Features

- **Real-Time Weather Data**: Get current temperature, humidity, and wind speed
- **Multi-Location Support**: Track weather for multiple cities and countries
- **Forecasts**: View upcoming weather predictions
- **Clean UI**: Modern, user-friendly interface for easy navigation
- **Country Coverage**: Access weather information worldwide

- **Language**: JavaScript
- **Package Manager**: npm
